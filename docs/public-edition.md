# Public edition — 2026-11-20

Prepared at the owner's request as an independent public repository. The
original repository remains private; this is a selected source snapshot with
new history, not a Git fork or mirror of private branches/tags.

- All 11 reflection entries and their Japanese overlays are original replacement
  copy. The lake verse is also original. The CMS sample uses the new text.
- The organizational logo is replaced by an original 20.11 mark, including the
  finale effect. Public metadata does not point to a production URL or image.
- Pet effects use the original Web Audio synthesizer. Stock recordings are not
  shipped and the code does not request missing recordings.
- Only the 54 current procedural scenery/prop GLBs are included. No withdrawn
  character meshes or optional local Meshy binaries are present.
- Private history, operations handoffs, QA screenshots/logs, account/session
  data, environment files and secrets are excluded. No production data is seeded.
- The private application and its database/configuration are not modified by
  publishing this repository. This project does not provide a public hosted demo.

Each release contains source/runtime archives, SHA-256 checksums and verification
evidence. Claims apply to the tested commit and environment. Real-device,
native-Japanese review and an operator's real SSO configuration remain separate
acceptance work; automated tests do not establish those results.
